# Changelog

## 0.1.0 · 2026-10-25

First public research release.

- Interactive directional-grating studio with target controls, exact geometry editing, physical field animation, spectra, search traces and JSON/SVG exports.
- Fourier-modal full-wave solver with a tested discrete adjoint and independent real-space FDFD verification.
- 9,600-case simulated dataset, geometry-level held-out evaluation, trained compact neural response/field models and explicit screening limitations.
- Direct-adjoint and random comparisons with retained traces, method-specific budgets and offline cost accounting.
- Verified 1550 nm design with 93.58595% target-order efficiency; independent check 93.58045%.
- Portable CLI and wheel with bundled studio/model/data assets; clean-directory package and HTTP checks; cross-platform CI.
- Publication review fixed unsupported surrogate order indexing, malformed optimizer geometry broadcasting and benchmark seed metadata. UI refinements clarify units, stale results, unsupported materials and field legends.

This is a 2D, lossless, constant-index study. It does not establish fabrication readiness, arbitrary photonic functionality or general ML acceleration.
