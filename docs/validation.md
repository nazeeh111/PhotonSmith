# Validation evidence

Checked 25 October 2026. All numbers below refer to saved artifacts in this checkout, not proposed future experiments.

| Requirement | Evidence and result |
| --- | --- |
| Nontrivial physical inverse design | The benchmark 1550 nm +1 sample directs 93.071% of incident power into +1 at M13. Its independently assembled real-space FDFD result is 93.037%. See `experiments/sample.json`. |
| Iterated working design | Live studio ML-assisted refinement reached M13 93.58595%, independent FDFD128 93.58045%, absolute difference 0.00551 percentage points and complex-field relative L2 difference 0.6502%. See `experiments/designs/1550nm-refined-config.json` and `interactive-refined-validation.json`. It is an additional experiment, not silently substituted into the benchmark. |
| Two independently assembled Maxwell formulations | Fourier-mode layer boundary matching with matrix exponentials vs real-space x/z sparse finite differences with separately integrated cell geometry. Fine-grid and Fourier refinement data are saved for the accepted designs. Both implementations are authored here; an external solver execution is not claimed. |
| Physics tests | 19 standard-library unittest tests pass in `docs/test-results.txt`: vacuum, analytic uniform slab, energy balance, symmetry, exact adjoint finite differences, longitudinal refinement, independent real-space solve, field shape/material, split integrity, dataset/model hash, neural gradient, gauge, constraints, API inputs, deterministic search, and fresh saved-sample re-simulation. |
| Installed package | A clean environment containing only PhotonSmith, NumPy and SciPy passed default CLI simulation, bundled-asset loading and all 11 HTTP workflows from outside the source checkout. |
| Actual application endpoints | 11 HTTP checks pass in `docs/http-qa.json`, including a real ML-assisted search, simulation, independent validation, field/spectrum dimensions and rejected invalid/out-of-domain requests. |
| Held-out ML evaluation | 2,400 independently sampled geometries, four wavelengths each; 1,680/360/360 geometry split. Test has 1,440 cases. Training-only mirror augmentation and PCA. Power MAE 5.824 percentage points; power RMSE 8.079 points; mean canonical complex-field relative L2 error 41.54%. The model is suitable for candidate screening, not an accepted physical field replacement. |
| Direct adjoint and non-ML comparison | 18 recorded searches: three objective combinations, two starts, three methods. Same paired starts and seeds, different explicitly recorded method budgets. Final M13 efficiencies, times, physical forward/adjoint counts and traces are in `experiments/benchmarks.json`. Mean efficiencies: random 57.91%, direct adjoint 80.51%, ML + adjoint 85.25%. |
| Additional objective checks | Independent refinements pass for 1410 nm order−1 and 1630 nm order+1. Their absolute efficiency disagreements are 0.05094 and 0.01479 percentage points. These are held-out optimization queries in the same family, not a new objective class or topology. |
| Compute accounting | Saved dataset generation 63.84 s; model training 328.60 s. The search-only median ratio is descriptive; varying local load, different budgets and offline cost prevent a broad end-to-end speedup claim. |
| Studio runtime | Actual in-app browser inspected at 1280×720 and mobile 390×844. Animated solved complex field; two periodic cells at equal physical x/z scale; width/center controls; target angle; spectral/history charts; benchmark table. Live optimization completed and its independent check passed. Multi-sample selection updates wavelength/order and restores matching saved validation. |
| Stale and failed result handling | Keyboard geometry edits mark the solution stale. Verify automatically simulates edited geometry first. Sample changes mark stale before the request. Standalone verification is attached to the result for export. |
| Real exports and replay | Browser-downloaded JSON retained the exact edited parameters and displayed passed validation. Downloaded SVG parsed with expected micrometre coordinate viewBox. The actual downloaded experiment replayed through the CLI with identical efficiency 0.9294826702258023. Screenshots are `docs/studio.png` and `docs/studio-full.png`. |
| Constraints | Per-layer lateral widths/gaps enforced. Vertical height and inter-layer junctions are not certified against a global minimum; exports explicitly mark fabrication readiness false. |
| Reproducibility | Dataset, geometry split indices, training metadata, portable `.npz` weights, learning curve, benchmark seeds/traces, sample configurations, runtime lock and SHA-256 manifests are included. CLI supports actual studio exports. |
| Scientific figures | `python -m photonsmith.figures` generated current `field.png`, `evidence.png`, and `surrogate.png`; each was visually inspected. |
| External foundations and licensing | Research and license docs cite Ceviche, Meep, NeuralOperator and JMLR2023. Optional Ceviche/Meep scripts compile and expose CLI help, but were not executed against those unavailable packages. Meep remains separate and unbundled. The runtime requires no paid service or API credentials. |

This supports the implemented 2D directional-grating scope. Arbitrary target spectra, wavelength splitting, waveguide conversion, 3D devices, measured dispersive materials and fabrication remain extensions, not delivered claims.
